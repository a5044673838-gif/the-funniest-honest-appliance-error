A toaster's honest error message for make.fun's "The Funniest Honest Appliance Error" bounty ($2 in USDC): it burned the toast because its human asked for "a little darker" and then walked away. The laugh comes from the truth of the fault, not a bolted-on pun. Pure Python standard library, no network, fully deterministic.

## Run it

```
python3 main.py
```

Writes `entry.txt` to `/output` (`MAKEFUN_OUTPUT_DIR` overrides).
